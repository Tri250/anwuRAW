## 1. 完成定义（Definition of Done）

本次测试按以下标准判定完成：

1. 六个模块的每个子功能至少对应 1 条自动化用例；交互路径、平台分支、错误路径分别建用例。
2. 用例不依赖真实 Tauri 后端、真实 RAW 解码、真实文件写入或真实 GPU；在边界处使用契约 Mock。
3. 全量测试连续通过，测试之间无 Store、Mock、定时器、DOM 残留。
4. `npx tsc --noEmit` 无类型错误。
5. 本轮修改的生产源码不新增 ESLint error，并顺手清理了 `ControlsPanel` 的 10 个历史 `no-explicit-any`；仓库既有 lint 债务与新增测试中的 Mock 类型债务单独记录。
6. 发现的产品缺陷必须附带回归用例；无法自动化或超出前端边界的项目列入“风险与不覆盖项”。

## 2. 测试环境与执行命令

```bash
cd /data/anwuRAW
npx vitest run
npx vitest run --coverage --coverage.reporter=json-summary --coverage.reporter=text
npx tsc --noEmit
```

- Node.js + jsdom；Vitest 配置见 `vitest.config.mts`。
- 全局测试初始化见 `tests/frontend/setup.ts`：隔离 Tauri `invoke`、文件对话框、`plugin-os`、Clerk、toast、ResizeObserver，并加载 zh-CN / en 两份 i18n 资源。
- 每个用例前重置 Zustand Store 和 Mock；每个用例后清理 DOM 与 500ms 历史防抖计时器。

## 3. 测试策略

| 层级 | 做法 | 目的 |
|---|---|---|
| 纯函数 | 直接调用 `cropUtils`、`maskUtils`、`adjustments`、`masterRecipes`、`usePresets` 等 | 覆盖几何计算、归一化、合并、排序、导入导出参数等确定性逻辑 |
| Hook | `renderHook` / 组件内真实 Hook，使用真实 Store 与假定时器 | 覆盖 500ms 防抖、并发守卫、切图保护、命令分发 |
| 组件 UI | 真实 zh-CN i18n，使用可访问角色/文本/`data-tooltip` 定位 | 覆盖面板、菜单、滑块、开关、对话框、拖拽、快捷键 |
| 跨 Store 集成 | 真实 `useEditorStore` / `useSettingsStore` / `useUIStore` / `useProcessStore` | 验证面板操作确实落到编辑器状态、设置持久化与状态机 |

| 错误与边界 | 后端 reject、空数据、非法输入、零宽容器、切图竞态、并发双击 | 验证错误提示、回滚、钳制与幂等 |

### 3.1 Mock 边界

- `@tauri-apps/api/core`：`invoke` 统一 Mock，按命令名返回测试数据；断言命令名与参数。
- `@tauri-apps/plugin-dialog`：`save` / `open` 默认返回 `null`（用户取消），用例按需注入路径或抛错。
- `@tauri-apps/plugin-os`：`mockPlatform` 默认 `linux`，Android 用例显式切换。
- Clerk、toast、ResizeObserver：隔离外部副作用。
- 其他 Tauri API（path/event/window/app）提供最小可用实现，避免组件挂载副作用。

### 3.2 用例编号规则

- 逐条用例编号：`TC-ADJ-###`、`TC-CROP-###`、`TC-MASK-###`、`TC-REPAIR-###`、`TC-PRESET-###`、`TC-EXP-###`、`TC-REG-###`。
- CSV 中同时保留源码测试标题里已有的历史编号（如 `TC-EXP-PANEL-27`、`TC-AI-07`），便于与既有测试对齐。
- 下文的“TC 范围”与 CSV 一一对应。

## 7. 风险与不覆盖项

1. **Rust/Tauri 后端真实行为**：本测试验证前端调用契约（命令名、参数、返回处理），不启动真实 Rust 后端；RAW 解码、GPU 渲染、真实文件写入需由后端集成测试或端到端测试补充。
2. **原生对话框与真实 Android 设备**：保存/打开对话框、系统返回键、触屏长按均以 Mock/事件模拟验证；真机权限与 SAF 路径仍需设备测试。
3. **视觉像素级回归**：Canvas 曲线、波形、直方图、水印预览验证的是 DOM 属性、路径与参数，不做像素截图对比。
4. **覆盖率未达 100% 的防御分支**：`MasksPanel`、`useAiMasking`、`Curves` 等仍有异常清理/极端防御分支未覆盖，但对应子功能主路径与关键错误路径均已覆盖。
5. **仓库既有 ESLint 债务**：全仓仍有大量历史 `no-explicit-any`；本轮未做全仓类型重构，避免扩大改动面。
