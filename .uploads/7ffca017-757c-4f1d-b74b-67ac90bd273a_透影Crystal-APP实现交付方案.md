# 透影 Crystal（Crystal One-Tap Editor）—— 同类型 APP 产品实现交付方案

> 依据三张设计稿 100% 还原功能 / UI / UX / 主题颜色，产出可直接进入开发的完整交付方案。
> 配套交付物：`crystal-ui-prototype.html`（可交互高保真原型，三屏可点、滑杆/开关/模板选中均可用）。

---

## 一、产品定位与目标

| 维度 | 定义 |
| --- | --- |
| 产品名 | 透影 Crystal —— 一键智能修图 APP |
| 一句话定位 | **照片预览更大 · 功能分区清晰 · 操作更高效** 的一键修图工具 |
| 目标用户 | 摄影爱好者（OM/Olympus 等相机用户）、风光/人像拍摄者、追求"拍完即修即发"的大众用户 |
| 核心价值 | 打开即改：AI 智能推荐滤镜 → 滑杆微调 → 带相机 EXIF 水印导出，3 步成片 |
| 品牌调性 | 暗夜黑金 · 专业克制 · 高效简洁（High效 · 专业 · 简洁） |

### 竞品对标

- **醒图 / 美图秀秀**：功能全但层级深、广告多 —— Crystal 以"零广告 + 三步极简"差异化
- **Lightroom Mobile**：专业但门槛高 —— Crystal 用 AI 推荐把专业参数"翻译"成一键应用
- **MX Player 式相机水印工具**：只加水印不修图 —— Crystal 覆盖"修图 + EXIF 水印"全链路

### 2.3 双强调色策略（关键设计决策）

设计稿采用**流程级双强调色**，这是本产品最鲜明的视觉签名：

- **琥珀金 #F5C842** → 修图编辑流程（图2 主界面）：传递"专业黑金相机"调性
- **青绿 #2FD6BF** → 水印/导出流程（图3）：传递"轻快完成、即将出片"的心理暗示
- 实现上以 `FlowAccent` 主题对象封装，页面路由进入 Watermark/Export 域时自动切换 accent，组件层零改动

### 3.2 七大分类 × 二级面板矩阵

| **预设**（金） | 子标签：✨推荐/自然/胶片/电影/人像/夜景/航拍 + 更多 ›；AI 智能推荐卡（"风光摄影 · Sky · Outdoor · Land" + 应用按钮）；滤镜缩略图横滑（冷调清透/湖泊清透/暖阳风光/**日落金色**/海洋蓝调）；强度滑杆 80 | 选中缩略图金色描边；AI 卡"应用"按钮写全链路参数 |
| **人像**（紫） | 肤色/磨皮/面部轮廓/眼部增强/背景虚化/重度磨皮/亮眼/更多 + 强度 50 | 工具格 4 列网格，按压态 #232320 |

| **调色**（蓝） | 曝光/对比度/高光/阴影/色温/饱和度/色调/更多 + 数值滑杆（30–50 双端） | 双端滑杆范围约束 |

| **AI 工具**（青） | AI增强/去雾/降噪/画面增强/天空识别/主体识别/超分辨率/更多 | 识别过程显示进度蒙层，失败不阻塞编辑 |
| **特效**（红） | 光景/暗角/颗粒/荧光/色彩氛围/镜头光晕/晕影/更多 | 叠加层实时预览（GPU 合成） |

### 3.3 底部操作区（图1"紧凑设计"还原）

`原图`（长按查看原图，松开恢复）· `撤销`（有历史可用）· `重做`（无历史置灰 #6F6F64）· `对比`（按住分屏对比）· `重置`（二次确认）· `保存`（金色高亮，导出至水印/导出流程）

### 3.4 水印与导出页（图3 逐项还原）

1. **双返回 + 相册入口**：胶囊返回钮 + 图片图标胶囊（快速换图）
2. **实时预览区**：左上 `● 实时预览`（青绿圆点徽章）、右上 `专业摄影` 徽章
3. **EXIF 信息栏**：`E-M10MarkIV | CRYSTAL(红) | 38mm f/5.6 1/200s ISO 200` —— 白底黑字，从照片元数据真实读取
4. **信息栏与相框总开关**：青绿 Switch（ON 状态 #2FD6BF）
5. **水印模板**：`6 款` 横滑卡片（专业摄影/极简高级/电影胶片/风光大片/街拍随行/黑白经典），选中青绿 2px 描边
6. **三操作**：收藏（星）/ **设为默认**（青绿实心勾）/ 保存模板
7. **导出格式**：JPEG｜PNG 分段控件（选中态 #3A3A34 亮块）
8. **字体**：`系统 ⇕`（可展开选择）；**画质**：高质量 100%

## 四、技术实现方案（对齐现有技术栈）

### 4.1 技术选型

| 层 | 方案 | 说明 |
| --- | --- | --- |
| 语言/框架 | **Kotlin 2.0.21 + Jetpack Compose (BOM 2024.09+)** | 与用户现有项目栈一致 |
| 网络 | Ktor 3.4.0 | 注意与 Kotlin 2.0.21 的兼容矩阵；仅素材同步用到，可后置 |
| 最小 SDK / Target | minSdk 29 / **targetSdk 35（Android 15）**，预留 36（Android 16）适配 | 满足 Android 15–16 无崩溃要求 |
| 图像管线 | BitmapFactory → RenderEffect / GPU Shader（LUT 应用）+ Coil3 异步解码大图 | 100MP 级照片走 BitmapRegionDecoder 分块 |
| 架构 | MVI + EditHistory（命令模式栈） | 撤销/重做即 History 栈出入栈 |

核心组件清单（与原型一一对应）：

- `CatNavBar`（七大分类，选中色由各分类专属 token 驱动 + 底部 22×3dp 金条指示器）
- `FilterThumbStrip`（LazyRow，选中 2dp 金描边 + 标签变金）
- `AiRecommendCard`（推荐理由标签化 + `apply()` 一键写入 EditStack）
- `ParamSlider`（金色/青绿双皮肤，`--p` 渐变轨道 = Compose 中用 `LinearGradient` brush）
- `ExifInfoBar`（白底黑字 Surface，EXIF 从 `ExifInterface` 真实读取，禁止伪造数据）
- `WatermarkTemplateCard` + `SegToggle`（JPEG/PNG）+ `TealSwitch`

### 4.3 功能实现要点

| 模块 | 实现路径 |
| --- | --- |
| 一键修图 | 预设 = LUT(3D cube) + 曲线 + 分割色调打包；点击即生成 EditOperation 入栈 |
| AI 智能推荐 | 端侧轻量场景分类（风景/人像/夜/美食）→ 命中规则库 → 推荐标签"风光摄影 · Sky · Outdoor · Land"，**推荐理由必须来自真实识别结果** |
| AI 工具 | 去雾/降噪：端侧模型（NCNN/ONNX Runtime Mobile）；天空/主体识别：DeepLab/Segment-Anything Mobile 蒸馏版 |
| 实时预览 | RenderEffect 硬件加速，预览分辨率按屏幕裁剪，导出才走全分辨率 |
| 对比 | 底部"对比"按压式：按下切原图、松开恢复；预览区左下浮层同逻辑 |
| EXIF 水印 | 读取真实 EXIF（机型/焦距/光圈/快门/ISO）渲染到白色信息栏 + 相框；无 EXIF 时显示拍摄时间兜底 |
| 撤销/重做 | EditHistory 命令栈（上限 50 步），重做无历史置灰 |

## 五、质量保障（对齐 Android 15–16 无崩溃要求）

| 项 | 措施 |
| --- | --- |
| 兼容性 | Android 15（edge-to-edge 强制）适配：`WindowInsets` 处理状态栏/导航栏，底部操作区 padding 接入手势区；Android 16 预留 predictive back |
| 稳定性 | 大图 OOM 防护（inSampleSize + Region 分块）；AI 模型加载失败降级为手动工具；全程无 Crash 上报门槛（Crash-free ≥ 99.8%） |
| 性能 | 冷启 ≤ 800ms；预览帧率 ≥ 60fps（GPU 合成）；导出 4K 图 ≤ 3s |
| 测试 | 真机矩阵（Android 12/13/14/15/16 各 ≥ 1 台）+ 真实照片数据集（风光/人像/夜景各 200 张）回归，**禁用占位假数据** |
| 隐私 | 相册权限按需申请；EXIF 中的 GPS 定位导出前默认剥离（合规默认值） |

## 七、风险与边界（Non-goals）

- **不做**：社交/社区、修图教程、账户体系 —— 保持工具纯粹性
- **风险**：AI 模型包体积（控制在 30MB 内，按需下载）；Ktor 3.4.0 与 Kotlin 2.0.21 兼容需锁定 `ktor-core 3.4.0 ↔ kotlin 2.0.21` 已验证组合
- **边界**：推荐标签仅当端侧识别置信度 ≥ 0.75 时展示，避免"假 AI"损伤专业口碑

> 配套原型：打开 `crystal-ui-prototype.html` 即可交互体验三个屏幕 —— 顶部按钮切换屏幕，主界面七大分类可点击切换二级面板，滑杆/开关/水印模板/导出格式均可操作。
