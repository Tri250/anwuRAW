# anwuRAW v2.1.13 · Android 端功能面板布局比例统一自检修复报告

- 仓库：https://github.com/Tri250/anwuRAW（已检出 `v2.1.13` 标签）
- 任务：人像 / 调色 / 构图 / 特效 功能面板 与 预设 / 滤镜 / AI工具 功能面板布局比例不统一，以预设/滤镜/AI工具面板为标准统一修复。

## 一、根因定位

七大分类面板由 `CrystalCategoryPanel.tsx` 路由容器分发，标准组（预设/滤镜/AI工具）在路由处被统一包裹在 `<div className="cx-panel">` 二级面板骨架内；而人像（PortraitPanel）、调色（TonePanel）、构图（ComposePanel）、特效（FxPanel）四个面板**直接返回裸内容，缺少 `cx-panel` 包裹层**。

`.cx-panel` 是面板布局比例的唯一定义源（`src/crystal.css` L445）：

```css
.cx-panel {
  flex: none;
  height: clamp(216px, 27vh, 268px);  /* 定高滚动区 */
  background: var(--cx-card);          /* 卡片底色 */
  border-top: 1px solid var(--cx-border);
  overflow-y: auto;
  padding: 12px 14px calc(env(safe-area-inset-bottom, 0px) + 12px);
}
```

由此产生三类布局比例偏差：

| # | 偏差 | 影响 |
|---|------|------|
| 1 | 高度/背景/内边距缺失 | 四个参数面板无定高（随内容撑开把底栏挤出屏幕外）、无卡片底色、无统一内边距，与标准面板观感和比例完全不同 |
| 2 | 滑杆皮肤作用域丢失 | `.crystal-shell .cx-panel .slider-input { accent-color }` 等三条作用域规则只对标准组生效，四个参数面板滑杆强调色/字号漂移 |
| 3 | 横屏网格脱位 | 横屏降级布局 `grid-area: panel` 仅匹配 `.cx-panel`，裸面板脱离网格（不落在面板区、高度规则失效） |

## 二、修复内容

仅改动 1 个文件：`src/components/mobile/CrystalCategoryPanel.tsx`（+30 / -5 行）

- 路由容器中 `tone / portrait / compose / fx` 四个分支统一补上 `<div className="cx-panel">` 包裹，与 `presets / filter / ai` 完全同构。
- 在路由容器处补充审计注释，说明标准与三类偏差来源，防止后续回归。
- 面板内部结构（标题 `cx-panel-title`、滑杆行、子分区、磁贴网格）本身与标准组同源（`crystalShared.tsx` 共享组件），包裹后自然对齐，无需额外改动。
