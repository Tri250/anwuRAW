1背景与目标

业务场景：「新疆合沐纯牛奶」在赣州市由经销商统一运营。货品为纯牛奶，仅 袋装 200ml 与 盒装 200ml 两个品类。业务模式为典型的快消品「经销商 → 终端门店」分销：公司设有 主仓库（总仓）与 赣州地区仓（区域分拨仓），业务员覆盖赣州市下辖的多个 外部客户终端门店（超市、便利店、母婴店等）。

核心痛点：牛奶是短保质期、强效期管理、高频客访、重促销的快消品。当前线下作业存在：库存与效期不透明、临期/过期损失高、门店要货与出库脱节、应收账期与回款靠手工、促销员作业与费用账目分散、各角色缺乏统一数据。

产品目标（可观测结果）：

  • 采购入库、门店要货、出库配送、退货、调拨、盘点全链路线上化，货权与数量可追溯至批次。
  • 对每一批次按 先进先出（先到期先出） 管理，到期前自动临期预警，过期自动冻结不可售。
  • 业务员在 Android 端完成巡店、要货、签收登记；促销员在 Android 端完成签到、陈列上传、销量上报。
  • 门店应收、账期、回款核销、对账单形成资金闭环，逾期自动预警。
  • 总经理、业务经理、业务员、促销员各自拥有匹配角色的数据看板与操作权限。
本 PRD 定义产品行为与业务决策，不涉及数据库、接口、前端框架等技术实现细节；技术架构由后续技术设计承接。

2范围

2.1 P0 最小闭环（必须上线才能跑通业务）

  • 基础档案：商品（袋装/盒装 200ml）、主仓库/地区仓、客户门店、供应商、角色账号。
  • 采购入库：采购申请 → 审批 → 验收入库（登记批次与保质期）→ 生成应付。
  • 门店要货与销售出库：业务员移动端要货 → 审核 → 按 FIFO 拣货出库 → 配送签收 → 生成应收。
  • 库存管理：分仓分批次库存查询、内部调拨、盘点、效期临期预警、过期冻结、报损。
  • 应收与回款：应收生成、账期与信用额度控制、回款核销、对账单、逾期预警。
  • 促销：活动方案、费用申请审批、促销员签到/陈列/销量上报、投入产出核算。
  • 权限与看板：四角色权限矩阵与各自数据看板。

2.2 P1 支持能力（上线后迭代增强）

  • 扫码枪 / 条码批量入库与拣货复核（PC 端与蓝牙扫码）。
  • 应收账期利息、折扣折让处理、红字冲销的分级权限。
  • 多价格体系（按客户等级 / 按门店维度的价格、最低售价管控）。
  • 供应商应付与付款登记、采购退货。
  • 拜访路线规划与地理围栏强校验。

2.3 排除项（本期不做）

  • 自有/直营门店的 POS 收银与门店日结（本期门店均为外部客户门店）。
  • 冷链温控物联网设备对接（本期均为常温 UHT 纯牛奶 [Assumption, TBD]）。
  • 与第三方财务软件（如金蝶/用友）的系统级自动对接。

4功能需求

本部分为文档主体。每个需求按「触发 → 处理规则 → 结果与状态变化 → 异常」描述。共享规则（权限、状态机、计算、效期、通知）统一定义于 第 5 章，各需求引用规则名而不重复。

4.1 基础档案（主数据）

FR-BA-01商品档案

触发：管理员（业务经理及以上）在 PC 端新增/维护商品。

处理规则：字段含商品编码（唯一）、名称、品类（袋装/盒装）、规格（200ml）、最小库存单位（袋/盒）、箱规（每箱袋数）、保质期天数、临期预警天数、条码、建议零售价、状态（启用/停用）。系统预置两 SKU：袋装 200ml、盒装 200ml。

结果：保存后商品可被采购、销售、库存引用；停用的商品不可新建单据但保留历史查询。

异常：商品编码重复 → 阻止保存并提示；已产生库存的商品不得删除，只能停用。

FR-BA-02仓库档案

触发：管理员维护仓库。默认两仓：主仓库、赣州地区仓。

处理规则：字段含仓库编码、名称、类型（总仓/地区仓）、地址、负责人、是否启用；仓库是否可作为销售出库仓 Assumption：主仓与地区仓均可作为出库仓，可在单据中指定。

结果：仓库用于库存、调拨、盘点、出库的归属维度。

FR-BA-03客户门店档案

触发：业务经理/业务员维护客户终端门店。

处理规则：字段含门店编码、名称、地址（定位坐标）、所属赣州下辖县区、门店类型（超市/便利店/母婴/其他）、联系人、电话、合作状态（正常/停用）、账期（天）、信用额度、结算方式、归属业务员。门店按县区分区，可指派到业务员负责片区。

结果：建档门店可被要货下单引用；账期与信用额度驱动销售审核与应收控制（见 FR-AR-02）。

异常：合作状态「停用」的门店不可新建销售单，但保留应收与历史。

FR-BA-04价格体系 P1

触发：业务经理维护销售价；可配置「统一价」或「按门店/客户等级价」。

处理规则：商品含基础销售价，支持最低售价（防低价）。当启用门店维度价格时，销售单优先取门店价，否则取基础价。价格调整需审批（规则见 SYS-审批）。

结果：生效后的价格作为销售单默认价，低于最低售价时订单需管审或总经理审批。

FR-BA-05供应商档案

触发：管理员维护供应商。字段含名称、联系人、电话、结算方式、账期（天）。用于采购单与应付。

FR-BA-06组织与人员（片区与归属）

触发：管理员维护账号、角色、片区。

处理规则：门店—业务员—业务经理形成归属关系；促销员按活动指派到门店。数据权限按片区/归属过滤（规则见 SYS-数据权限）。

4.2 采购管理

FR-PUR-01采购申请

触发：业务经理在 PC 端发起采购申请（或由低库存预警引导）。

处理规则：选择供应商、商品、数量、入库仓（默认主仓库）。单据初态「草稿」。

结果：提交后进入「待审批」。

FR-PUR-02采购审批

触发：采购申请提交后进入审批流。

处理规则：由总经理审批；超出金额阈值需额外确认 TBD 阈值。审批通过 → 「待收货」；驳回 → 退回草稿并附原因。

FR-PUR-03采购入库验收

触发：供应商送货到仓，仓管/业务经理在 PC 端做入库验收。

处理规则：逐批次登记：生产日期 + 保质期天数 自动计算到期日；录入实收数量（可部分收货）；超出采购数量需另建单或触发超收确认。入库即增加对应仓的该批次库存。

结果：生成「应付账款」（金额 = 实收数量 × 采购单价）；生成库存变动流水（入库）。

异常：实收数量与采购单不符 → 按实收入账，差异留痕并可补单；到期日早于当前日期（已过期）→ 阻止入库并提示。

FR-PUR-04采购退货（退供应商）P1

触发：入库后发现质量问题，向供应商退货。

处理规则：创建采购退货单，选择来源采购单与批次，出库扣减库存，冲减应付或生成应收退款。

FR-PUR-05供应商应付与付款P1

触发：管理员登记向供应商的付款。

处理规则：显示供应商应付余额、账期到期日；登记付款并核销应付。逾期未付预警。

4.3 销售与订货

FR-SAL-01门店要货（销售单创建）

触发：业务员在 Android 端拜访门店时发起要货（也可由 PC 端代录）。

处理规则：选择客户门店、商品、数量、期望送达、出库仓（默认地区仓或主仓）。系统自动带出价格与账期，实时校验可用库存（规则见 CALC-可用库存）与信用额度（FR-AR-02）。单据初态「草稿」，可保存后继续编辑。

结果：提交后进入「待审核」，锁定对应库存。

异常：库存不足 → 提示缺货数量并阻止提交或转「预订」TBD；门店停用 → 阻止新建。

FR-SAL-02价格与账期校验

触发：销售单创建/修改时。

处理规则：售价低于最低售价、或账期/信用额度超限、或价格有折扣折让时，标记需审批（规则见 SYS-审批）。

FR-SAL-03订单审核

触发：销售单处于「待审核」。

处理规则：业务经理审核（价格、账期、库存、客户状态）；通过 → 「待拣货」；驳回 → 退回草稿注明原因，释放锁定库存。

FR-SAL-04拣货与出库（FIFO）

触发：订单审核通过后，仓管按单拣货。

处理规则：系统按 先到期先出（FIFO） 自动推荐批次（规则见 CALC-FIFO）；确认后扣减批次库存，状态 → 「待配送」。

异常：推荐批次部分数量不足 → 延续到下一到期批次；扫码/人工复核不一致 → 阻止出库并提示。

FR-SAL-05配送与签收

触发：货物送达门店。

处理规则：配送状态 → 「配送中」；门店签收（业务员 Android 端代签收并可选上传签收凭证），支持「全部签收」「部分签收 + 拒收」。签收成功 → 状态「已签收」并 生成应收（金额 = 签收数量 × 单价 − 折让，规则见 CALC-应收）。

异常：部分拒收 → 拒收部分生成销售退货或冲减发货；未签收前应收不生成。

FR-SAL-06销售退货

触发：门店退回临期/破损/滞销货品。

处理规则：创建销售退货单，关联原销售单，选择退货批次与数量、退货原因。收货后入库，判定「可再售」（未过期）或「报损/冻结」（临期或破损）。退货冲减应收并扣减该批次相应数量（可再售时）。

结果：退货入库并更新应收，状态流转见 状态机。

FR-SAL-07订单取消/作废

触发：订单在发货前需要撤销。

处理规则：「草稿/待审核」可自行取消；「已审核/待拣货」需权限作废并释放锁定库存；「已出库/配送中」不可作废，走退货流程。作废留痕不可物理删除。

4.4 库存管理

FR-INV-01库存查询

触发：各角色查看库存。

处理规则：按仓库 + 商品 + 批次维度查询：现存量、可用量、锁定量、冻结量、到期日、临期/过期状态。支持 PC 列表与 Android 简版查询。

FR-INV-02内部调拨

触发：主仓库向地区仓补货，或反向调拨。

处理规则：创建调拨单（调出仓/调入仓/商品/批次/数量），出库扣减调出仓、到货入库增加调入仓；支持「一步调拨」或「出库 + 到货确认」两步 TBD。调拨不计入货权与应收。

异常：调出仓库存不足 → 阻止提交。

FR-INV-03盘点

触发：仓管定期或抽查盘点某仓。

处理规则：创建盘点单（仓库/商品范围）→ 录入实盘数量（支持移动端扫码录入）→ 提交差异 → 审批 → 生成盘盈盘亏并调整库存，生成库存变动流水。盘点期间可锁定盘点商品禁止进出 TBD。

FR-INV-04效期管理（临期预警 / 过期冻结）

触发：入库登记批次后，系统按到期日持续计算。

处理规则：到期日 − 当前日期 ≤ 商品「临期预警天数」→ 该批次标记「临期」并预警；到期日 < 当前日期 → 标记「过期」并 冻结不可售、不可出库，转入待报损。临期批次在出库拣货时按 FIFO 优先消耗。预警推送规则见 SYS-通知。

FR-INV-05报损 / 报废

触发：过期、破损、盘亏等需减少库存并留痕。

处理规则：创建报损单（商品/批次/数量/原因/金额），审批后扣减库存。盘亏由盘点单直接产生，不重复减。

FR-INV-06库存变动流水

触发：任何库存增减（入库/出库/调拨/盘点/报损/退货）。

处理规则：自动记录：时间、仓库、商品、批次、变动类型、数量、关联单据号、操作人。不可修改，用于追溯与审计。

FR-INV-07库存预警（低库存/缺货）

触发：系统按商品设置的安全库存比对可用量。

处理规则：可用量 ≤ 安全库存 → 低库存预警；可用量 = 0 → 缺货预警。预警按仓库维度，推送至业务经理（规则见 SYS-通知）。

4.5 应收与回款（资金闭环）

FR-AR-01应收生成

触发：销售单签收（FR-SAL-05）。

处理规则：按签收数量与价格生成应收，计算规则见 CALC-应收；退货自动冲减（FR-SAL-06）。

结果：门店形成应收余额与账期到期日。

FR-AR-02账期与信用额度控制

触发：销售单创建/审核时。

处理规则：门店账期（天）用于推算应收到期日；信用额度为门店可欠款上限。当「当前应收余额 + 本单金额」> 信用额度 → 阻止审核或需总经理特批 TBD。

FR-AR-03回款登记与核销

触发：财务（或业务员现场代登记）收到门店回款。

处理规则：登记回款（金额、日期、方式：现金/转账、凭证），按先进先出核销到应收单；支持一次回款核销多笔应收。产生回款记录留痕。

结果：应收余额减少或结清；结清状态可查。

FR-AR-04对账单

触发：定期（或业务经理发起）生成门店对账单。

处理规则：汇总某周期内门店的销售、退货、回款，生成应收期初/本期发生/回款核销/期末余额，可导出或推送门店确认；对账差异标注待核对。

FR-AR-05逾期预警与催收

触发：系统按应收到期日判断。

处理规则：到期未结清 → 「逾期」，按逾期天数分级（如 0–30 / 30–60 / >60 TBD），推送至归属业务员与业务经理催收；记录催收处理过程为可选。

4.6 促销管理

FR-PRO-01促销活动方案

触发：业务经理创建促销活动（含袋装/盒装指定）。

处理规则：字段含活动名称、类型（特价/买赠/满减/陈列）、商品、参与门店（按片区或指定门店）、起止时间、促销价或赠品规则、执行员（促销员）、预算费用。初态「草稿」。

FR-PRO-02促销费用申请与审批

触发：活动方案中的费用/预算部分。

处理规则：费用（物料、赠品、场地、人员补贴等）随活动或单独发起申请，经业务经理初审、总经理终审；审批通过后活动进入「执行中」，费用占用预算。

FR-PRO-03促销员作业（签到/陈列/销量上报）

触发：促销员到店执行活动。

处理规则：Android 端：到达门店 签到（定位）、执行结束 签退；上传 陈列照片（货架/堆头，可含商品与品牌位置）；登记 销量上报（活动期间销售袋/盒数量，可选按天）；登记赠品/物料使用。

结果：作业记录关联活动与门店，供投入产出核算。

异常：签退早于签到、定位与门店坐标偏差超出阈值 → 提示校验/需说明 TBD 阈值。

FR-PRO-04促销价/买赠执行（与销售联动）

触发：活动执行期间，门店要货引用促销商品。

处理规则：销售单对参与活动的门店与商品自动取促销价/买赠规则，并在单据上标识活动来源；超出活动时间或门店范围则回落到正常价。

FR-PRO-05投入产出核算

触发：活动结束（或结束 + 结算期后）。

处理规则：汇总活动费用（物料+赠品+补贴）与产出（活动期销量、销售额、毛利），产出 投入产出比 报表；支持结论标记（完成/未达标）。数据质量依赖销量上报与销售单的准确归因 Assumption。

4.7 拜访与巡店（业务员现场作业）

FR-VIS-01拜访计划

触发：业务经理为业务员编排（或业务员自建）拜访计划。

处理规则：按日/周安排拜访门店，与片区门店归属对应；Android 端展示当日拜访清单。

FR-VIS-02巡店签到与定位

触发：业务员到达门店。

处理规则：签到记录时间与定位，留痕拜访轨迹；可选上传现场照片。

FR-VIS-03陈列与效期检查上报

触发：巡店过程中检查货架。

处理规则：上报陈列照片与位置、库存陈列数量、临期/过期检查结果（发现临期可发起退换货建议）。结果关联门店与拜访记录。

FR-VIS-04补货建议 / 下次要货

触发：巡店结束。

处理规则：根据门店陈列存量与历史销量，给出补货建议 → 一键转为销售单（FR-SAL-01）。

4.8 数据分析与看板

FR-RPT-01总经理经营看板

内容：总销售/毛利（袋装 vs 盒装对比）、库存总量与效期分布、临期/过期金额、应收总额与逾期、促销投入产出汇总、各区域/门店排名。PC 端为主。

FR-RPT-02业务经理区域/门店/员工业绩看板

内容：所辖门店销售达成 vs 目标、业务员业绩排名、门店欠款与逾期、低库存与临期预警明细、促销执行进度。

FR-RPT-03业务员个人看板

内容：个人销售目标达成、负责门店清单与状态、当日拜访任务、待催收回款、待处理退货。Android 端为主。

FR-RPT-04库存与效期分析

内容：库存周转、临期/过期批次清单、报损分析、安全库存命中情况。

FR-RPT-05促销投入产出分析

内容：活动费用 vs 产出、活动 ROI、门店维度执行与销售对比（对应 FR-PRO-05）。

4.9 系统与权限

FR-SYS-01账号与角色权限

处理规则：账号绑定角色与片区归属；权限矩阵见 权限矩阵；支持角色可配置，但默认提供四角色。

FR-SYS-02审批流配置

处理规则：采购、价格/折让、退款、促销费用、盘点差异、报损等走审批；支持按金额/条件配置多级审批 TBD 具体阈值；审批支持通过/驳回/转交，全程留痕。

FR-SYS-03消息通知

处理规则：待审批、临期/过期、低库存、逾期回款、活动开始/结束、退货等按角色推送（站内 + 可选手机推送）；推送时机与接收人见 SYS-通知。

FR-SYS-04操作日志与审计

处理规则：关键操作（审批、作废、报损、盘点调整、价格修改、回款核销）记录操作人、时间、前后值，不可删改。

FR-SYS-05数据权限（片区/门店范围）

处理规则：业务员仅见所属门店数据；业务经理见所辖片区；总经理与财务见全局（财务范围另行配置 TBD）。促销员仅见所参与活动与门店。

5.2 对象状态机（权威定义）

对象允许状态关键流转与禁止操作
采购单 草稿 → 待审批 → 待收货 → 部分收货 → 已收货（完成）；驳回；取消 驳回/取消仅限待收货前；已收货不可取消；部分收货可多次直至完成
销售单 草稿 → 待审核 → 待拣货 → 待配送 → 配送中 → 已签收（完成）；驳回；作废 草稿/待审核可取消；已审核可作废释放库存；配送中不可作废走退货；签收后生成应收
销售退货单 待审核 → 待收货 → 已收货（分可再售/报损）→ 完成 收货后冲减应收并按批次回库
调拨单 草稿 → 待出库 → 待到货 → 已到货（完成）；取消 到货确认前可取消；出库与到货两侧需核对一致
盘点单 草稿 → 盘点中 → 待审批 → 已完成（产生盘盈盘亏） 审批通过才允许库存调整
应收单 未结清 → 部分核销 → 已结清；未结清→逾期 回款按 FIFO 核销；退货冲减
促销活动 草稿 → 待审批 → 已通过/执行中 → 已结束 → 已核算；驳回 审批通过前不可执行；结束后进入核算
批次（区段） 正常 → 临期 → 过期（冻结） 过期冻结不可售/不可出库，仅可报损

5.3 计算与精度规则

规则名定义说明
CALC-计量单位库存统一按最小单位（袋/盒）计；箱规仅做换算与「箱 + 零散」展示1 箱 = 箱规袋数，由商品档案配置
CALC-可用库存可用量 = 现存量 − 锁定量（待拣货/待出库）− 冻结量（过期/待报损）销售单校验与安全库存据此计算
CALC-FIFO出库按批次「到期日升序」优先，同到期日按入库先后优先消耗临期批次
CALC-到期日到期日 = 生产日期 + 保质期天数入库登记时自动计算
CALC-应收应收金额 = 签收数量 × 单价 − 折让；退货再冲减折让需权限与审批
CALC-金额精度单价/金额保留 2 位小数，四舍五入 Assumption跨单据汇总以分后精度累加
CALC-信用额度当前应收余额 + 本单金额 ≤ 信用额度超限阻止审核或特批
CALC-临期/过期临期：到期日 − 今日 ≤ 临期天数；过期：到期日 < 今日阈值由商品档案配置

事件接收人时机

5.5 审计与追溯（SYS-审计）

  • 库存变动流水不可修改，覆盖入库/出库/调拨/盘点/报损/退货。
  • 审批、作废、报损、盘点调整、价格修改、回款核销记录操作人 + 时间 + 前后值。
  • 退货、逾期、临期相关证据（签收凭证、照片）保留并可溯源到单据。
