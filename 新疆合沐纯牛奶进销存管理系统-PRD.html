2. 背景与目标

观察到的业务问题：乳品为短保质期快消品，进销存依赖批次与效期；赣州区域经销商存在多仓库 / 门店铺货、客户普遍赊销月结的特点。手工台账 / 零散表格带来：

  • 批次与效期不可追踪，临期 / 过期无法及时识别，存在食品安全与报废损失风险；
  • 赊销账目易错漏，客户应收、供应商应付、对账核销不可靠；
  • 多仓库 / 门店数据不互通，难以调拨与盘清；
  • 业务员现场开单、查库存、确认欠款缺乏工具，易超信用额度发货。

产品决策：建设以「批次效期 + 应收应付」为核心的进销存系统，PC 端支撑后台全流程与经营分析，Android 端支撑现场作业。

可观测结果（定性）：每笔出入库可追溯到具体批次与到期日；临近效期可预警并优先出清；每笔赊销自动形成应收、收款逐单核销、余额实时可对账；多仓库存实时互通；业务员现场开单收款、超额度被拦截。

5.2 采购管理

5.2.1 采购入库（FR-PUR-01）

用途：供应商采购入库，形成批次库存并增加应付。
触发：采购员新建（可直接入库，或由「采购订单」生成）。

选供应商→ 录明细（商品/批次/生产日期/数量/进价）→ 自动算到期日与金额→ 提交审核→ 审核通过 · 入库生效
  • 批次号可自动生成（采购单号+序号）或录入厂家生产批次；
  • 到期日 = 生产日期 + 保质期天数，自动算可纠正；
  • 审核后：增加该地点批次库存 + 增加供应商应付。

5.2.2 采购退货（FR-PUR-02）

选供应商、商品、具体批次、数量；数量 ≤ 该批次库存；审核后减库存、冲减应付；退回已过期批次允许但需备注。

5.2.3 采购订单（FR-PUR-03 · P1）

预采购计划，不产生库存与应付；到货可部分/全量生成采购入库单。

5.3 销售管理

5.3.1 销售出库（FR-SAL-01）

用途：销售牛奶，按 FEFO 扣减批次，形成应收或收款。
触发：业务员（PC / Android）新建销售单。

选客户→ 选商品/数量（按级别取价）→ 信用额度校验→ 保存 FEFO 分配→ 提交审核→ 出库生效
  • 售价按客户级别默认带回可改，折扣见 6.3；
  • 赊销：审核后增应收；现款：审核后直接生成收款；
  • 信用额度超限处置见 6.4（默认拦截需审批）；
  • FEFO 分配见 6.2，支持有权限手动指定批次；
  • 库存不足默认拦截提交。

异常：库存不足、信用超限、客户/商品停用、批次过期（默认禁售，仅可报废）。

5.3.2 销售退货（FR-SAL-02）

选客户、商品、数量，指定回库批次；审核后增库存、冲应收；退回已过期商品入「待报废」冻结仓。

5.3.3 移动端现场开单（FR-SAL-03）

能力说明
快速开单选客户 → 商品 → 数量 → 提交；支持条码扫码 / 编码输入（一期）
现场收款开单后引导收款登记（现金 / 扫码转账），核销本次应收
欠款与对账查客户应收余额、账期、未结清单
库存与效期查各仓批次库存与临期情况
凭证拍照单据 / 收货签字 / 收款凭证拍照留存（一期）

网络：一期为在线实时；离线开单为二期。

5.4 库存管理

5.4.1 库存查询（FR-INV-01）

维度内容
汇总库存商品按地点 / 全公司总数量（分袋装、盒装）
批次库存批次号、生产日期、到期日、剩余天数、数量、状态（在库/临期/过期）

5.4.2 批次与效期管理（FR-INV-02）

  • 临期预警：到期前 30 天（全局默认，可按商品覆盖）进入临期，推送并支持优先出清；
  • 过期批次：自动「已过期」冻结，禁止销售出库，只能走报废；
  • 报废：生成报废单，减库存记损益，审核留痕。

5.4.3 库存调拨（FR-INV-03）

同主体内点位间调拨（含批次迁移）。状态：草稿 → 待出库 → 在途 → 已完成；可作废。源地点 FEFO 扣减、目标地点录实收批次数量，在途数量单独可见。

5.4.4 库存盘点（FR-INV-04）

新建盘点单（选地点、商品/分类）→ 录实盘（含批次）→ 提交审核 → 生成盘盈/盘亏并调库存；差异需填原因，盘亏留痕。

5.4.5 库存预警（FR-INV-05）

统一预警规则见 6.4：效期预警（临期/过期）+ 低库存预警。

5.5 财务与对账

5.5.1 应收 / 应付台账（FR-FIN-01）

台账维度公式
应收客户期初 + 销售 − 退货 − 收款 = 余额
应付供应商期初 + 采购 − 采购退货 − 付款 = 余额

5.5.2 收款 / 付款核销（FR-FIN-02）

收款单：选客户 → 金额与方式（现金/银行/扫码）→ 核销应收（按单逐笔或部分核销）。
付款单：选供应商 → 金额与方式 → 核销应付。
支持「预收/预付」；收款超余额允许但提示记预收；被核销单据须已审核。

5.5.3 客户对账单（FR-FIN-03）

按客户生成期间往来对账单（期初、销售、退货、收款、期末），分袋装/盒装汇总，供月结打印/发送。

5.6 报表与统计（FR-RPT）

报表维度指标
销售报表日/月/商品/客户/门店/业务员数量、金额、毛利
库存报表地点/商品/批次数量、效期分布、临期占比
采购报表供应商/商品/时间进货数量、金额、退货
应收账龄客户0-30/31-60/60+ 天、超额度客户
经营分析周期销售额、成本、毛利、报废损失

毛利 = 售价 − 批次成本（批次移动加权平均）；支持导出 Excel / 打印。

6. 共享规则

6.1 单据状态机

进销存业务单据（采购/销售/退货/盘点）：

草稿→ 待审核→ 已审核（生效）
状态可执行操作
草稿编辑、删除、提交、作废
待审核审核通过、驳回（回草稿）、作废
已审核只读；更正走「红冲」反向单据，不可直接改删

调拨单：草稿 → 待出库 → 在途 → 已完成（可作废）。

已审核单据不可直接编辑删除；更正统一「红冲（负数反向单据）+ 留痕」，保证账务与审计可追溯。

6.2 FEFO 出库规则

定义：销售/调拨出库时，按批次到期日最早优先自动分配。

分配顺序：到期日由早到晚 → 到期日相同按「入库时间最早」→ 再按「批次号升序」。

  • 「已过期」批次不参与自动分配，禁止销售出库；
  • 支持有权限用户手动指定批次（须库存充足、未过期）；
  • 批次与数量在审核通过时锁定扣减，避免并发超卖。

6.3 计算规则

项目规则
单据金额∑(数量×单价) − 折扣；整单/单品折扣，四舍五入到分
税额价税口径 = 含税一口价；税率字段默认 13% 保留，支持日后价税分离
应收余额Σ已审核销售 − Σ已审核销售退货 − Σ已核销收款
应付余额Σ已审核采购 − Σ已审核采购退货 − Σ已核销付款
批次库存Σ入库 − Σ销售出库 − Σ调出 + Σ调入 + Σ盘盈 − Σ盘亏 − Σ报废
单位换算基本单位与整箱换算，内部统一按基本单位核算
到期日生产日期 + 保质期天数
成本 / 毛利批次移动加权平均；毛利 = 售价 − 批次成本

6.4 预警与通知

预警触发通知
临期到期前 30 天（可配/可商品覆盖）仓管、业务员、主管；App 推送 + PC 待办
过期已到期仓管、管理员；强制报废待办
低库存库存 ≤ 安全库存采购员、管理员

信用额度超限（已定稿）：默认「拦截并需审批」，有权限者放行；可为指定客户设「仅警告」白名单。
