## 1. 结论摘要

本轮没有改动 Rust 图像处理管线，重点处理发布链路、权限面、首屏体积和可验证性。共修复 10 类问题，其中 3 类会直接影响发布完整性：

1. 同一版本的 `workflow_dispatch` 与 tag push 可能并发构建（concurrency 按分支/tag 分裂）。
2. 发布收尾只检查构建 job 成功，不检查资产是否真的上传；资产缺失时仍可能发布空 release。
3. 发布产物没有统一校验文件，用户无法验证下载完整性。

## 3. 性能

### 3.1 构建体积

| 指标 | 优化前 | 优化后 | 变化 |
| --- | --- | --- | --- |
| 主入口 JS | 2,449.45 kB（gzip 713.83 kB） | 2,016.99 kB（gzip 602.13 kB） | -432.46 kB（-17.7%） |
| 设置页 | 在主包内 | 56.13 kB 独立 chunk，打开设置时才加载 | 延后加载 |
| 全局弹窗 | 在主包内 | 98.60 kB 独立 chunk | 从首包拆出 |
| Clerk | 在主包内 | 130.51 kB 独立 vendor chunk | 缓存隔离 |
| UI 依赖 | 在主包内 | 151.53 kB 独立 vendor chunk | 缓存隔离 |

改动：

- `vite.config.mjs` 增加 `clerk-vendor`、`ui-vendor` 拆包规则。
- `SettingsPanel` 使用 `React.lazy` + `Suspense`，仅在设置页打开时加载。
- `AppModals` 拆为独立异步 chunk，降低主包解析压力。
- `index.html` 的 Poppins 从 18 个字重降为实际使用的 4 个（400/500/600/700），减少字体请求与 CSS 体积。
- favicon 改为相对路径，适配 Tauri custom protocol。

### 3.2 仍需关注

主 chunk 仍有约 2.0 MB（gzip 602 kB）。进一步下降需要把右侧面板（蒙版、AI、预设、导出）改成按面板懒加载，属于中等风险重构，未在本轮发布窗口内实施。

## 6. 安装与卸载

新增 `README.md` 的 **Installation, Verification & Uninstall**：

- 发布页新增 `SHA256SUMS.txt`，由 GitHub Release asset 的 `sha256` digest 生成，不重复下载大文件。
- Windows：NSIS current-user 安装，无需管理员；卸载不删除照片与 `.rrdata` sidecar。
- macOS：DMG 拖拽安装；明确说明当前未签名/未公证及 Gatekeeper 处理方式；给出版本数据与缓存目录。
- Linux：deb/rpm/AppImage 安装命令；包名经 release 产物验证为 `anwu-raw`；说明 `_tethering` 依赖与 Ubuntu 24.04 的 `libfuse2`。
- Android：sideload 与卸载方式；未配置签名 secrets 时明确标记为 debug 签名测试包。

## 9. 残留风险与后续建议（按优先级）

1. **代码签名**：仓库未配置 Apple Developer ID、Windows 代码签名、Android keystore。macOS 首次启动需右键打开，Windows 可能触发 SmartScreen，Android 为 debug 签名。需要在仓库/`release` environment 配置 secrets 后重新发布。
2. **CSP**：当前为 `null`。建议下一版本先在测试构建中启用白名单 CSP，验证 Clerk 登录、Google Fonts、GitHub 更新检查、本地 AI 面板后再进入正式发布。
3. **Clerk 测试 key**：`pk_test_...` 硬编码在 `App.tsx`。建议改为 `import.meta.env.VITE_CLERK_PUBLISHABLE_KEY`，CI 用 repository variable 注入。
4. **持久化原子写**：`save_settings`/`save_presets` 仍直接 `fs::write`，断电或崩溃时可能留下截断 JSON。建议改为临时文件 + fsync + rename（需要 Rust 变更与全平台编译验证）。
5. **退出路径**：`RunEvent::ExitRequested` 中 `prevent_exit()` 后直接 `process::exit(0)`，会跳过部分析构。建议单独评估。
6. **Flatpak manifest**：`packaging/io.github.CyberTimon.RapidRAW.yml` 仍指向 v1.3.13 与旧 ORT 哈希，不在本次 release 链路内，但已过期。
7. **Lint 告警**：80 条（未使用变量、i18n literal），已不再阻塞 CI；建议逐步清零。
