### 0.2 结果判定标准

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| **PASS** | 实际结果与预期完全一致，无异常 | 放行 |
| **FAIL** | 实际结果与预期不一致（功能错误/数据错误/UI 错乱） | 阻断当前功能发布，提交缺陷 |
| **BLOCKED** | 前置条件无法满足（依赖缺失/环境问题），无法执行 | 记录阻塞原因，待条件满足后复测 |
| **WARN** | 功能可用但存在非阻断问题（文案、性能、样式） | 记录，可优化，不阻断发布 |

### 0.3 功能验收总原则（七大功能通用）

1. **不崩溃、不卡死**：所有操作（含快速连续点击、极端输入）不产生 Crash / ANR / WebView 无响应；
2. **数据一致**：编辑结果所见即所得，保存/恢复/导出后数据一致，重进应用不丢失；
3. **非破坏性编辑**：原图永不被动覆盖，RAW 源文件保持不变，编辑以“参数/会话”方式持久化；
4. **离线可用**：不依赖网络的本地功能（除云 AI/图库社区外）在飞行模式下必须可用；
5. **触摸友好**：所有可交互目标触控区域≥44×44dp，滑杆/画笔支持单指精确操作，支持双指缩放画布；
6. **系统级适配**：横竖屏切换、系统返回键、多任务切回、低内存回收后均正确恢复；
7. **权限最小化**：仅在必要时申请存储/照片权限，拒绝授权时给出可恢复的引导，不崩溃。

## 2. 元数据（Metadata）专项

**实现要点（源码依据）**：`MetadataPanel.tsx` 提供文件信息（文件名/格式/尺寸/像素/拍摄时间）、相机参数（光圈/快门/ISO/焦距/镜头）、作者信息（标题/作者/版权/评论，可编辑）、组织（星级/颜色标签/标签）、GPS（离线地图+在线地图链接）、扩展 EXIF；多选批量更新，支持分组扩展与虚拟副本（VC）标识。

### 2.1 功能用例（MD 组）

| 用例 ID | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| MD-01 | 打开含完整 EXIF 的 RAW | 打开元数据面板 | 文件信息区显示文件名、扩展名、宽高、百万像素、拍摄时间 |
| MD-02 | 同上 | 查看相机参数区 | 光圈显示 `f/2.8` 格式、快门带 `s`、ISO、焦距带 `mm`、镜头型号，缺项显示 `-` |

| MD-12 | 展开“评级与标签” | 点击 1~5 星 | 星级正确高亮；再次点击同一星可取消；星级数量与库内状态一致 |
| MD-13 | 同上 | 点击颜色标签（无/红/黄/…） | 当前选中标签出现选中环标识；切换标签互斥 |
| MD-14 | 同上 | 输入框输入标签回车 | 标签以 chip 形式添加并持久化 |
| MD-15 | 已有标签 | 点击标签上的 × | 标签被移除 |

| MD-20 | 扩展 EXIF 存在 | 查看面板底部 | 其余 EXIF 条目按字母序展示，标签名格式化（如 `ExposureMode`→`Exposure Mode`） |
| MD-21 | 元数据编辑（作者字段） | 编辑后立即退出应用再重进 | 修改已持久化，重新打开显示新值 |

### 2.2 元数据验收标准

1. 文件信息、相机参数、GPS、扩展 EXIF 四类数据展示完整且格式正确；
2. 标题/作者/版权/评论 4 个字段可编辑、可清空、可持久化；
3. 星级（1-5）、颜色标签（≥6 色+清除）、标签（增/删/快捷键）全部生效且跨会话保持；
4. 多选批量写入（含分组扩展）覆盖全部目标图片，单失败不影响其余；
5. Android 专项：无 GPS 权限请求（仅读 EXIF 字节）；返回键可关闭作者/组织折叠区；无网络时在线地图链接仍可展示但由系统浏览器处理。
