## 2. 逐模块升级规划

### M1 图像处理引擎（A 级 — 2.0 的技术底座）

**现状与痛点**: WGSL 管线成熟，但 CPU 后备路径与 GPU 行为靠人工对齐（dehaze/glow/channel mixer 等各自手写）；wgpu 曾因 P3 色偏被迫降级（Cargo.toml L27 注释），色彩管理是补丁式而非体系化。

| 升级项 | 内容 | 验收标准 |
|---|---|---|
| E1 调整项契约测试 | 70+ 参数在 CPU/GPU 双路径的黄金样本回归（16 张基准图 × 全参数扫描） | 同参数双路径 ΔE2000 < 1.0，CI 阻断 |
| E2 色彩管理体系化 | 显式工作空间（scene-referred linear）→ 显示/导出 ICC 全链路，终结 P3 类色偏 | P3/ sRGB / AdobeRGB 显示器用例回归零色偏 |
| E3 性能基线体系 | bench/ 扩展为 4 场景发版回归：开图 / 拖滑杆 p95 / 批量导出 / 万张库浏览 | 滑杆 p95 < 50ms（4K RAW），每版 CI 出报告 |
| E4 中间缓存升级 | 蒙版/调整中间结果统一 16bit float 缓冲，消除 8bit 量化链 | 放大 400% 无 banding |

### M2 库管理 / DAM（A 级 — 专业用户粘性的主战场）

**现状与痛点**: file_management 是全仓最大模块（4336 行），能力面已宽但**索引依赖文件系统直读**，万张级目录的搜索/过滤/智能检索缺乏持久化结构；智能相册、地图视图空缺。

| 升级项 | 内容 | 验收标准 |
|---|---|---|
| D1 持久化索引 | SQLite（或等价）元数据索引库：EXIF/评分/标签/编辑状态，增量刷新 | 10 万张库冷启动索引 < 3s，搜索 < 100ms |
| D2 智能相册 | 保存的查询（规则 = 现有 EXIF query 语法 + 标签/评分/色标） | 规则可命名/嵌套，与现有查询语法 100% 兼容 |
| D3 地图视图 | GPS 聚合地图 + 按地域筛选（元数据面板已有 GPS 地图，升级为库级） | 聚合加载 1 万点 < 1s |
| D4 去重中心 | 在 auto culling（模糊/重复检测）之上加确认式批量清理流 | 误杀率 < 1%（种子库回归） |
| D5 大库性能专项 | 虚拟化滚动/缩略图管线在 10 万张级验证 | 滚动掉帧 < 5% |

### M3 导出与 CLI（A 级 — 专业交付的最后一公里）

**现状与痛点**: 格式面已宽，但缺 ICC 色彩配置、16bit、DNG/HDR 导出；批量队列不可暂停；gap spec 的 FR-8/FR-9 在途。

| 升级项 | 内容 | 验收标准 |
|---|---|---|
| X1 ICC 端到端 | sRGB/AdobeRGB/Display P3 嵌入（消化 gap spec FR-8） | 导出文件被色彩感知软件正确识别 |
| X2 色深选择 | 8/16bit 显式 UI（消化 gap spec FR-9） | 16bit TIFF 可被检测工具识别 |
| X3 DNG 导出 | 编辑结果写回 DNG（数字负片归档）+ HDR 格式（AVIF/HDR JPEG） | Lightroom 可打开并识别元数据 |
| X4 批量队列 2.0 | 可暂停/续跑/重试的任务队列 + 失败清单 | 100 张批量中断后可续跑不重复 |
| X5 CLI 对齐 | CLI 支持全部新导出参数（ICC/色深/DNG） | GUI 与 CLI 输出 byte 级一致性抽查 |

### M4 AI 套件（A 级 — 商业化载体）

**现状与痛点**: 本地模型矩阵完整，但模型下载/存储/更新散落各处；云端服务仅有占位；Clerk 已进依赖表；移动端无硬件加速（gap spec 明确 non-goal）。

| 升级项 | 内容 | 验收标准 |
|---|---|---|
| A1 模型管理器 | 统一的模型下载/更新/存储路径/版本 UI + 完整性校验 | 断点续传，sha256 校验，离线可用 |
| A2 云服务 GA | 账号（Clerk）+ 云端 Inpainting/增强 + 订阅；云端代码同仓开源（AGPL 合规红线） | SLA 99.5%；免费/自托管/云三轨矩阵与 README 承诺一致 |
| A3 移动端 AI 加速 | Android NNAPI/Delegate 评估落地（2.0 解禁 gap spec non-goal） | 移动端 AI 蒙版 < 2s（中端机型） |
| A4 模型许可审计 | SAM2/LaMa/NIND 等许可证矩阵文档化 | 无商用冲突项遗留 |

### M5 蒙版系统（B 级 — 定向增强）

现状成熟度最高（A-，且是唯一有测试文件的模块群）。2.0 不重构，只补工作流短板：

- **蒙版可视化树 + 命名**：多容器/子蒙版的可读性管理（复杂度已达 PhotoShop 图层级，但缺导航手段）；
- **蒙版跨图复用**：复制蒙版到选中批次（复制粘贴已支持，升级为批量）；
- **范围蒙版直方图拾取**：亮度/颜色范围蒙版直接从画面点选取样（现为滑杆盲调）。

验收：蒙版树支持 20 容器 + 每容器 10 子蒙版场景下可导航可命名；点选取样后蒙版覆盖率与手动调参一致。

### M6 多帧合成（B 级 — 旗舰功能载体）

- **N1 天文摄影堆栈**（README priorities 第一条）：GPU 星点对齐 + mean/median/sigma-clipping，输出 32bit 线性合成 —— M2 Beta 交付；
- **N2 HDR 输出链**：HDR 合成结果导出为 AVIF/HDR JPEG（与 M3-X3 联动）；
- **N3 全景手动修正**：拼接失败时的控制点手动微调（现为全自动黑盒）。

验收：15 张星空序列堆叠 < 60s（桌面 GPU）；HDR 输出文件在 TV/支持 HDR 的浏览器正确显示。

### M7 元数据（B 级）

- 完成 gap spec 在途项：IPTC 读写（FR-6）+ 批量元数据编辑（FR-7）；
- **XMP 写回策略选项**（嵌入 / sidecar / 关闭），服务与 Lightroom 互操作用户；
- 验收：与 Lightroom 往返读写 XMP 字段零丢失（种子文件回归）。

### M8 RAW 解码（C 级 — 维护）

- rawler fork 打 tag 固定 rev（消化审计 P1-8），建立上游 dnglab 同步节奏（季度）；
- 相机支持矩阵自动化冒烟（每版抽样 20 机型解码回归）；
- 不做：自研解码器、双解码库。

### M9 预设与工作流（B 级）

- **P1 预设云同步**：随 A2 云服务上线（跨设备同步预设/LUT/导出预设）；
- **P2 预设版本历史**：预设内含来源/版本，社区预设可更新推送；
- **P3 快捷键速查浮层**：`?` 呼出 cheetsheet（自定义快捷键体系已有，缺发现性）；
- 不做：预设 AI 推荐（价值/成本比低）。

### M10 色彩管理（B 级，与 M1-E2 合并执行）

- soft proofing：按导出色域模拟预览 + 溢色警告（M1-E2 的直接消费方）；
- LUT 面板升级：LUT 缩略图缓存与搜索（现面板在 LUT 多时不可用）；
- 验收：开启 soft proofing 后 AdobeRGB→sRGB 溢色区域标红准确。

### M11 移动端（A 级 — 平台完整性）

- **B1 完成 gap spec 全部 9 个 FR**（通道混合器/分离色调/AI 拉直/颜色+亮度范围蒙版/IPTC/批量元数据/ICC/色深）—— M1 Alpha 前清零；
- **B2 iOS TestFlight alpha**（只读浏览 + 基础调整，总规划已定义）；
- **B3 性能档位**：静态预览默认化 + 低配设备自动降级策略；
- 验收：gap spec 综合评分 83.6 → 93+ 达标；Play 商店过审。

### M12 联机拍摄（C 级 — 维护）

- 保持 macOS/Linux 双平台，不追加 Windows（README 已论证 WPD 驱动冲突，决策维持）；
- 仅做：相机兼容矩阵季度回归 + 内存泄漏修复；
- 2.1+ 再评估。

## 3. 模块依赖与执行顺序

```
M1-E1/E2 契约测试+色彩管理 ──┬──> M3-X1/X2 (ICC/色深导出) ──> M10 soft proofing
                             └──> M6-N2 (HDR 导出)
M11-B1 gap spec 清零 ──────────> M1 Alpha 门槛
M4-A2 云服务 ─────────────────> M9-P1 预设同步
M2-D1 索引库 ─────────────────> D2 智能相册 > D3 地图 > D4 去重（严格串行）
```

**关键排序原则**：
1. M1 契约测试先行 —— 它是所有处理类改动的安全网，晚于任何引擎变更落地都会返工；
2. M2 索引库串行推进（D1→D2→D3→D4），避免并行重构文件_management；
3. M11-B1 是唯一"已在途"的承诺（gap spec），必须最先清零兑现。

## 5. 范围裁决清单

**2.0 明确不做**（防止范围蠕变，与总规划 Non-Goals 对齐）：
- 人脸识别 / 视频编辑 / 插件市场（总规划 Non-Goals）
- Windows 联机拍摄（驱动冲突，技术上不可行）
- 自研 RAW 解码器（rawler 生态成熟，维护成本不匹配）
- 预设 AI 推荐（低价值高成本）
- M5/M8 蒙版与解码重构（成熟度已高，重构风险大于收益）

**可裁剪顺序**（带宽不足时从下往上砍）：N3 全景手动修正 → D3 地图 → P3 速查 → A3 移动 AI 加速 → N1 天文堆栈。**不可裁剪**：M1-E1 契约测试、M2-D1 索引、M11-B1 gap 清零、M4-A2 云服务。
