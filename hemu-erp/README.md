# 新疆合沐纯牛奶进销存管理系统 V1.0 正式版

主仓库 + 赣州区域 + 多门店 一体化进销存。PC 网页端 + 安卓移动端（PWA，可添加到主屏幕获得全屏 App 体验），开箱即用，无需配置数据库。

## 一、快速启动

**环境要求**：Node.js ≥ 22.5（依赖内置 `node:sqlite`），无需安装任何数据库。

| 平台 | 操作 |
|---|---|
| Windows | 双击 `start.bat` |
| Linux / macOS | `bash start.sh` 或 `npm start` |

启动后浏览器访问 **http://localhost:8080**。

**安卓移动端**：手机与电脑连接同一 Wi-Fi，浏览器打开 `http://电脑IP:8080`，菜单选择「添加到主屏幕 / 安装应用」即可获得全屏 App（图标自动生成、离线缓存静态资源）。

## 五、验收清单（冒烟路径）

1. **登录**：四账号分别登录，工作台按角色呈现差异化看板。
2. **业务员开单**：sales01 登录 → 新建订单 → 选门店、填 2 箱 → 系统自动显示赠半箱、应收 ¥100 → 提交审批。
3. **经理审批**：mgr 登录 → 待办中心 → 订单审批通过 → 整单出库（总仓库存扣减）。
4. **回款闭环**：sales01 登记回款 ¥100 → mgr 确认到账 → 订单自动转「已完成」。
5. **促销验证**：开 4 箱 → 自动赠 1 箱（16 件），赠品行零元；开 1 箱 + 3 散 → 无赠品（散件不参与）。
6. **零售 POS**：promo01 登录 → 零售开单 → 选数量 → 结算 → 本店库存即时扣减。
7. **领货闭环**：promo01 领货申请 → mgr 审批 → 货物在途 → promo01 确认收货（支持短少登记）。
8. **采购入库**：mgr 采购入库 → 总仓库存增加，库存流水可查。
9. **临期预警**：工作台「⏰ 临期预警」卡片 → 临期预警中心（紧急≤3天/临期≤10天/过期三档）→ 库存页「批次」查看明细 → mgr/gm 登记报废（自动核减库存+审计）。出库全程 FIFO「先到期先出」自动扣减批次，调拨跨库转移保质期。
10. **角色功能**：#me 个人中心查看各角色功能清单（总经理 7 项 / 经理 6 项 / 业务员 5 项 / 促销员 5 项），菜单与数据范围随角色自动收敛。
11. **权限拦截**：促销员访问用户管理接口返回 403；业务员仅能查看本人订单。
12. **报表核对**：报表中心销售趋势 / 门店排行 / 业务员回款率 / 促销让利与订单明细一致。
13. **移动端**：Android Chrome 打开 → 添加到主屏幕 → 全屏运行、图标正确。

## 六、技术架构

- **后端**：Node.js 22 原生 `node:sqlite` + Express，JWT 鉴权、RBAC 角色矩阵、关键写操作全事务化（库存/资金原子更新）、登录失败锁定、审计日志。
- **前端**：零框架原生 ES Module SPA；自研「天山青」设计系统（精细字体层级 + 表格数字等宽对齐）；PC 侧边导航 / 移动底部标签双布局。
- **数据**：单文件 SQLite（`data/hemu.db`），首次启动自动建表与种子数据（演示门店、14 天订单流水）。
- **PWA**：manifest + Service Worker 静态缓存 + 自绘品牌图标。
